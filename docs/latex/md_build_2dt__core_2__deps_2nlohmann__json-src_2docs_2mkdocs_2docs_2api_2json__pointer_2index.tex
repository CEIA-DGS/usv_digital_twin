A JSON pointer defines a string syntax for identifying a specific value within a JSON document. It can be used with functions \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2at}{\`{}at\`{}}{0} and \`{}operator\mbox{[}\mbox{]}\`{}. Furthermore, JSON pointers are the base for JSON patches.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2json__pointer_2index_autotoc_md990}{}\doxysection{\texorpdfstring{Template parameters}{Template parameters}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2json__pointer_2index_autotoc_md990}
