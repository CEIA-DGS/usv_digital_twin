\item Compares whether one JSON value {\ttfamily lhs} is greater than another JSON value {\ttfamily rhs} according to the following rules\+:
\begin{DoxyItemize}
\item The comparison always yields {\ttfamily \#!cpp false} if (1) either operand is discarded, or (2) either operand is {\ttfamily NaN} and the other operand is either {\ttfamily NaN} or any other number.
\item Otherwise, returns the result of {\ttfamily \#!cpp !(lhs \texorpdfstring{$<$}{<}= rhs)} (see \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2operator__le}{\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}operator\texorpdfstring{$<$}{<}=\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}}{0}).

!!! note "{}\+Comparing \`{}\+Na\+N\`{}"{} \begin{DoxyVerb}`NaN` values are unordered within the domain of numbers.
The following comparisons all yield `#!cpp false`:
  1. Comparing a `NaN` with itself.
  2. Comparing a `NaN` with another `NaN`.
  3. Comparing a `NaN` and any other number.
\end{DoxyVerb}
