Read from input and generate SAX events


\begin{DoxyEnumerate}
\item Read from a compatible input.
\item Read from a pair of character iterators

The value\+\_\+type of the iterator must be an integral type with size of 1, 2 or 4 bytes, which will be interpreted respectively as UTF-\/8, UTF-\/16 and UTF-\/32.
\end{DoxyEnumerate}
