\doxysubsection{Detailed Description}
ROS 2 Node responsible for bridging ROS data to the Digital Twin Core. 

This node subscribes to telemetry, navigation, and environmental data (GPS, IMU, AIS, Waypoints), converts the ROS messages into domain-\/specific types, and updates the core digital twin state.
