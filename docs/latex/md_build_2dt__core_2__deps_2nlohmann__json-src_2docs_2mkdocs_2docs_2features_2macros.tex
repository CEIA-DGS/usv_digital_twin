This macro enables extended diagnostics for exception messages. Possible values are {\ttfamily 1} to enable or {\ttfamily 0} to disable (default).

When enabled, exception messages contain a \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2features_2json__pointer}{JSON Pointer}{0} to the JSON value that triggered the exception, see \href{../home/exceptions.md\#extended-diagnostic-messages}{\texttt{ Extended diagnostic messages}} for an example. Note that enabling this macro increases the size of every JSON value by one pointer and adds some runtime overhead.

The diagnostics messages can also be controlled with the CMake option {\ttfamily JSON\+\_\+\+Diagnostics} ({\ttfamily OFF} by default) which sets {\ttfamily JSON\+\_\+\+DIAGNOSTICS} accordingly.

The library targets C++11, but also supports some features introduced in later C++ versions (e.\+g., {\ttfamily std\+::string\+\_\+view} support for C++17). For these new features, the library implements some preprocessor checks to determine the C++ standard. By defining any of these symbols, the internal check is overridden and the provided C++ version is unconditionally assumed. This can be helpful for compilers that only implement parts of the standard and would be detected incorrectly.

See \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__cpp__11}{full documentation of \`{}\+JSON\+\_\+\+HAS\+\_\+\+CPP\+\_\+11\`{}, \`{}\+JSON\+\_\+\+HAS\+\_\+\+CPP\+\_\+14\`{}, \`{}\+JSON\+\_\+\+HAS\+\_\+\+CPP\+\_\+17\`{}, and \`{}\+JSON\+\_\+\+HAS\+\_\+\+CPP\+\_\+20\`{}}{0}.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2features_2macros_autotoc_md1389}{}\doxysection{\texorpdfstring{$<$tt$>$\+JSON\+\_\+\+HAS\+\_\+\+FILESYSTEM$<$/tt$>$, $<$tt$>$\+JSON\+\_\+\+HAS\+\_\+\+EXPERIMENTAL\+\_\+\+FILESYSTEM$<$/tt$>$}{<tt>JSON\_HAS\_FILESYSTEM</tt>, <tt>JSON\_HAS\_EXPERIMENTAL\_FILESYSTEM</tt>}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2features_2macros_autotoc_md1389}
When compiling with C++17, the library provides conversions from and to {\ttfamily std\+::filesystem\+::path}. As compiler support for filesystem is limited, the library tries to detect whether {\ttfamily \texorpdfstring{$<$}{<}filesystem\texorpdfstring{$>$}{>}}/{\ttfamily std\+::filesystem} ({\ttfamily JSON\+\_\+\+HAS\+\_\+\+FILESYSTEM}) or {\ttfamily \texorpdfstring{$<$}{<}experimental/filesystem\texorpdfstring{$>$}{>}}/{\ttfamily std\+::experimental\+::filesystem} ({\ttfamily JSON\+\_\+\+HAS\+\_\+\+EXPERIMENTAL\+\_\+\+FILESYSTEM}) should be used. To override the built-\/in check, define {\ttfamily JSON\+\_\+\+HAS\+\_\+\+FILESYSTEM} or {\ttfamily JSON\+\_\+\+HAS\+\_\+\+EXPERIMENTAL\+\_\+\+FILESYSTEM} to {\ttfamily 1}.

See \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__filesystem}{full documentation of \`{}\+JSON\+\_\+\+HAS\+\_\+\+FILESYSTEM\`{} and \`{}\+JSON\+\_\+\+HAS\+\_\+\+EXPERIMENTAL\+\_\+\+FILESYSTEM\`{}}{0}.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2features_2macros_autotoc_md1390}{}\doxysection{\texorpdfstring{$<$tt$>$\+JSON\+\_\+\+NOEXCEPTION$<$/tt$>$}{<tt>JSON\_NOEXCEPTION</tt>}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2features_2macros_autotoc_md1390}
