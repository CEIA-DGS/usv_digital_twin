\chapter{Digital Twin -\/ CEIA-\/\+DGS}
\hypertarget{md_README}{}\label{md_README}\index{Digital Twin -\/ CEIA-\/DGS@{Digital Twin -\/ CEIA-\/DGS}}

\Hypertarget{md_README_autotoc_md1891}%
 O {\bfseries{Digital Twin}} é um módulo de simulação, predição e visualização em tempo real desenvolvido para Veículos de Superfície Não Tripulados (USVs).

Este sistema é capaz de processar cartas náuticas oficiais (S-\/57), gerar malhas de navegação (Nav\+Mesh) em tempo de execução, calcular dinamicamente o risco de colisão e exibir diagnósticos operacionais em uma interface gráfica dedicada.

\hypertarget{md_README_autotoc_md1893}{}\doxysection{\texorpdfstring{Arquitetura do Sistema}{Arquitetura do Sistema}}\label{md_README_autotoc_md1893}
O projeto foi dividido em quatro pacotes para garantir a separação de responsabilidades (SoC) e a independência do motor matemático em relação ao middleware de comunicação\+:


\begin{DoxyItemize}
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily dt\+\_\+core}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Motor central em C++ puro (independente do ROS). Responsável por todo o processamento geométrico (GDAL/\+Boost), R-\/\+Trees, estruturas de dados matemáticas (Types) e os algoritmos de predição de risco de colisão.
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily \doxylink{namespacedt__msgs}{dt\+\_\+msgs}}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Definição das mensagens customizadas (IDL) para tráfego de dados de navegação e alertas no barramento do ROS 2.
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily \doxylink{namespacedt__ros}{dt\+\_\+ros}}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Nó adaptador (Padrão Adapter). Atua como uma ponte, inscrevendo-\/se nos tópicos de sensores do USV e traduzindo os dados brutos para injetá-\/los no {\ttfamily dt\+\_\+core}.
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily dt\+\_\+viz}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Interface Gráfica de Diagnóstico desenvolvida em Qt5. Renderiza a Nav\+Mesh, a telemetria do USV, os alvos dinâmicos e os alertas visuais de colisão, rodando em uma thread assíncrona.
\end{DoxyItemize}
