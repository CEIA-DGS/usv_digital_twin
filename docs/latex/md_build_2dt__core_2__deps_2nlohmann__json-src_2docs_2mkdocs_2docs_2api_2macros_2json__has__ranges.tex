This macro indicates whether the standard library has any support for ranges. Implies support for concepts. Possible values are {\ttfamily 1} when supported or {\ttfamily 0} when unsupported.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__ranges_autotoc_md1171}{}\doxysection{\texorpdfstring{Default definition}{Default definition}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__ranges_autotoc_md1171}
The default value is detected based on the preprocessor macro {\ttfamily \#!cpp \+\_\+\+\_\+cpp\+\_\+lib\+\_\+ranges}.

When the macro is not defined, the library will define it to its default value.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__ranges_autotoc_md1172}{}\doxysection{\texorpdfstring{Examples}{Examples}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__has__ranges_autotoc_md1172}
