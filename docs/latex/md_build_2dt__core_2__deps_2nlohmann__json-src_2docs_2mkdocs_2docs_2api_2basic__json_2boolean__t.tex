The type used to store JSON booleans.

\href{https://tools.ietf.org/html/rfc8259}{\texttt{ RFC 8259}} implicitly describes a boolean as a type which differentiates the two literals {\ttfamily \#!json true} and {\ttfamily \#!json false}.
