The function restores the arbitrary nesting of a JSON value that has been flattened before using the \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2flatten}{\`{}flatten()\`{}}{0} function. The JSON value must meet certain constraints\+:


\begin{DoxyEnumerate}
\item The value must be an object.
\item The keys must be JSON pointers (see \href{https://tools.ietf.org/html/rfc6901}{\texttt{ RFC 6901}})
\item The mapped values must be primitive JSON types.
