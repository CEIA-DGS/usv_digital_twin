 Message\+Pack is an efficient binary serialization format. It lets you exchange data among multiple languages like JSON. But it\textquotesingle{}s faster and smaller. Small integers are encoded into a single byte, and typical short strings require only one extra byte in addition to the strings themselves.

- [MessagePack specification](https://github.com/msgpack/msgpack/blob/master/spec.md)
\end{DoxyVerb}

!!! success "{}\+Complete mapping"{} \begin{DoxyVerb}The mapping is **complete** in the sense that any JSON value type can be converted to a MessagePack value.

Any MessagePack output created by `to_msgpack` can be successfully parsed by `from_msgpack`.
\end{DoxyVerb}
 !!! warning "{}\+Size constraints"{} \begin{DoxyVerb}The following values can **not** be converted to a MessagePack value:

  - strings with more than 4294967295 bytes
  - byte strings with more than 4294967295 bytes
  - arrays with more than 4294967295 elements
  - objects with more than 4294967295 elements
\end{DoxyVerb}
 !!! info "{}\+Na\+N/infinity handling"{} \begin{DoxyVerb}If NaN or Infinity are stored inside a JSON number, they are serialized properly in contrast to the
[dump](../../api/basic_json/dump.md) function which serializes NaN or Infinity to `null`.
\end{DoxyVerb}
