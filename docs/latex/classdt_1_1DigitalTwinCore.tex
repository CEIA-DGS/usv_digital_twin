\doxysubsection{Detailed Description}
Primary interface and state manager for the Digital Twin. 

Implements a Double-\/\+Buffering / Lock-\/\+Free paradigm for consumers. Asynchronous data writers update the internal state, while high-\/frequency readers pull the latest immutable snapshot.
