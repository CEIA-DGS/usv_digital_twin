\doxysubsection{Detailed Description}
Utilitário responsável por exportar as estruturas geradas da Nav\+Mesh para arquivos vetoriais (Shapefiles). 

Atua como uma classe estática pura, encapsulando as operações de I/O em disco e conversão geométrica utilizando a biblioteca GDAL/\+OGR.
