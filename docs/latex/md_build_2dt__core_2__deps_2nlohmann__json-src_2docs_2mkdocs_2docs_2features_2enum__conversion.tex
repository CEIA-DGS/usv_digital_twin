 By default, enum values are serialized to JSON as integers. In some cases this could result in undesired behavior. If an enum is modified or re-\/ordered after data has been serialized to JSON, the later de-\/serialized JSON data may be undefined or a different enum value than was originally intended.

It is possible to more precisely specify how a given enum is mapped to and from JSON as shown below\+:

Other Important points\+:


\begin{DoxyItemize}
\item When using {\ttfamily template get\texorpdfstring{$<$}{<}ENUM\+\_\+\+TYPE\texorpdfstring{$>$}{>}()}, undefined JSON values will default to the first pair specified in your map. Select this default pair carefully.
\item If an enum or JSON value is specified more than once in your map, the first matching occurrence from the top of the map will be returned when converting to or from JSON.
\item To disable the default serialization of enumerators as integers and force a compiler error instead, see \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__disable__enum__serialization}{\`{}\+JSON\+\_\+\+DISABLE\+\_\+\+ENUM\+\_\+\+SERIALIZATION\`{}}{0}.
