Controls how exceptions are handled by the library.


\begin{DoxyEnumerate}
\item This macro overrides \href{https://en.cppreference.com/w/cpp/language/try_catch}{\texttt{ {\ttfamily \#!cpp catch}}} calls inside the library. The argument is the type of the exception to catch. As of version 3.\+8.\+0, the library only catches {\ttfamily std\+::out\+\_\+of\+\_\+range} exceptions internally to rethrow them as \href{../../home/exceptions.md\#out-of-range}{\texttt{ {\ttfamily json\+::out\+\_\+of\+\_\+range}}} exceptions. The macro is always followed by a scope.
\item This macro overrides {\ttfamily \#!cpp throw} calls inside the library. The argument is the exception to be thrown. Note that {\ttfamily JSON\+\_\+\+THROW\+\_\+\+USER} should leave the current scope (e.\+g., by throwing or aborting), as continuing after it may yield undefined behavior.
\item This macro overrides {\ttfamily \#!cpp try} calls inside the library. It has no arguments and is always followed by a scope.
\end{DoxyEnumerate}\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__throw__user_autotoc_md1202}{}\doxysection{\texorpdfstring{Parameters}{Parameters}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2json__throw__user_autotoc_md1202}
