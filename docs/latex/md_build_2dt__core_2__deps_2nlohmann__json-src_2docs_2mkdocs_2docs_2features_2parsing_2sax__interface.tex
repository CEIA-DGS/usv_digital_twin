The return value of each function determines whether parsing should proceed.

To implement your own SAX handler, proceed as follows\+:


\begin{DoxyEnumerate}
\item Implement the SAX interface in a class. You can use class {\ttfamily nlohmann\+::json\+\_\+sax\texorpdfstring{$<$}{<}json\texorpdfstring{$>$}{>}} as base class, but you can also use any class where the functions described above are implemented and public.
\item Create an object of your SAX interface class, e.\+g. {\ttfamily my\+\_\+sax}.
\item Call {\ttfamily \#!cpp bool \doxylink{classnlohmann_1_1basic__json_a12b382c6407da5543827ce4b24bb5008}{json\+::sax\+\_\+parse}(input, \&my\+\_\+sax);} where the first parameter can be any input like a string or an input stream and the second parameter is a pointer to your SAX interface.
\end{DoxyEnumerate}

Note the {\ttfamily sax\+\_\+parse} function only returns a {\ttfamily \#!cpp bool} indicating the result of the last executed SAX event. It does not return {\ttfamily json} value -\/ it is up to you to decide what to do with the SAX events. Furthermore, no exceptions are thrown in case of a parse error -\/ it is up to you what to do with the exception object passed to your {\ttfamily parse\+\_\+error} implementation.
