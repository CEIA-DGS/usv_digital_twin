The parser callback distinguishes the following events\+:


\begin{DoxyItemize}
\item {\ttfamily object\+\_\+start}\+: the parser read {\ttfamily \{} and started to process a JSON object
\item {\ttfamily key}\+: the parser read a key of a value in an object
\item {\ttfamily object\+\_\+end}\+: the parser read {\ttfamily \}} and finished processing a JSON object
\item {\ttfamily array\+\_\+start}\+: the parser read {\ttfamily \mbox{[}} and started to process a JSON array
\item {\ttfamily array\+\_\+end}\+: the parser read {\ttfamily \mbox{]}} and finished processing a JSON array
\item {\ttfamily value}\+: the parser finished reading a JSON value
