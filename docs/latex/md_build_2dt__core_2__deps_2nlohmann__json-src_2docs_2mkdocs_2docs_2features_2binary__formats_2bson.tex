 BSON, short for Binary JSON, is a binary-\/encoded serialization of JSON-\/like documents. Like JSON, BSON supports the embedding of documents and arrays within other documents and arrays. BSON also contains extensions that allow representation of data types that are not part of the JSON spec. For example, BSON has a Date type and a Bin\+Data type.
