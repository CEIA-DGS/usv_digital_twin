The library supports {\bfseries{JSON Pointer}} (\href{https://tools.ietf.org/html/rfc6901}{\texttt{ RFC 6901}}) as alternative means to address structured values. A JSON Pointer is a string that identifies a specific value within a JSON document.

\DoxyCodeLine{\ \ \ \ \ \ \ \ "{}one"{}:\ 1,}
\DoxyCodeLine{\ \ \ \ \ \ \ \ "{}two"{}:\ 2,}
\DoxyCodeLine{\ \ \ \ \ \ \ \ "{}three"{}:\ [true,\ false]}
\DoxyCodeLine{\ \ \ \ \}}
