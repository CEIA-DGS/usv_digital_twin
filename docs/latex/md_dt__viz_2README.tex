 Pacote responsável pela interface gráfica do módulo Digital Twin do projeto CEIA-\/\+DGS.

A aplicação foi desenvolvida em {\bfseries{C++}}, utilizando {\bfseries{Qt 5}} e {\bfseries{ROS 2 Humble}}, com o objetivo de apresentar uma visualização bidimensional em vista superior dos principais elementos relacionados à navegação do USV.

A interface permite visualizar\+:


\begin{DoxyItemize}
\item Zona livre de navegação;
\item Posição e orientação do USV;
\item Embarcações monitoradas;
\item Trajetória percorrida pelo USV;
\item Derrota planejada;
\item Waypoints ativos;
\item Alertas visuais de risco de colisão.
\end{DoxyItemize}

\DoxyHorRuler{0}
\hypertarget{md_dt__viz_2README_autotoc_md2}{}\doxysection{\texorpdfstring{Objetivo}{Objetivo}}\label{md_dt__viz_2README_autotoc_md2}
O pacote {\ttfamily dt\+\_\+viz} tem como objetivo fornecer uma ferramenta de diagnóstico visual para os dados produzidos pelos demais módulos do sistema.

Nesta etapa, a interface recebe\+:


\begin{DoxyItemize}
\item A derrota planejada do USV;
\item Os waypoints ativos da rota;
\item Alertas de colisão associados a uma embarcação específica.
\end{DoxyItemize}

Quando um alerta de colisão é recebido, a interface identifica o alvo pelo MMSI e altera sua aparência visual.

\end{DoxyCode}
