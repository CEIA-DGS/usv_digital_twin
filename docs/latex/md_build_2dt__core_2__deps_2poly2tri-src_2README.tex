Since there are no Input validation of the data given for triangulation you need to think about this. Poly2\+Tri does not support repeat points within epsilon.


\begin{DoxyItemize}
\item If you have a cyclic function that generates random points make sure you don\textquotesingle{}t add the same coordinate twice.
\item If you are given input and aren\textquotesingle{}t sure same point exist twice you need to check for this yourself.
\item Only simple polygons are supported. You may add holes or interior Steiner points
\item Interior holes must not touch other holes, nor touch the polyline boundary
\item Use the library in this order\+:
\begin{DoxyEnumerate}
\item Initialize CDT with a simple polyline (this defines the constrained edges)
\item Add holes if necessary (also simple polylines)
\item Add Steiner points
\item Triangulate
\end{DoxyEnumerate}
\end{DoxyItemize}
