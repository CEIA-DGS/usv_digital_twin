\item Exchanges the contents of the JSON value with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated.
\item Exchanges the contents of the JSON value from {\ttfamily left} with those of {\ttfamily right}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated. Implemented as a friend function callable via ADL.
\item Exchanges the contents of a JSON array with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated.
\item Exchanges the contents of a JSON object with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated.
\item Exchanges the contents of a JSON string with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated.
\item Exchanges the contents of a binary value with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated.
\item Exchanges the contents of a binary value with those of {\ttfamily other}. Does not invoke any move, copy, or swap operations on individual elements. All iterators and references remain valid. The past-\/the-\/end iterator is invalidated. Unlike version (6), no binary subtype is involved.
