This macro evaluates to the full name of the {\ttfamily nlohmann} namespace.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2nlohmann__json__namespace_autotoc_md1239}{}\doxysection{\texorpdfstring{Default definition}{Default definition}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2nlohmann__json__namespace_autotoc_md1239}
The default value consists of the root namespace ({\ttfamily nlohmann}) and an inline ABI namespace. See \href{../../features/namespace.md\#structure}{\texttt{ {\ttfamily nlohmann} Namespace}} for details.

When the macro is not defined, the library will define it to its default value. Overriding this value has no effect on the library.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2nlohmann__json__namespace_autotoc_md1240}{}\doxysection{\texorpdfstring{Examples}{Examples}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2macros_2nlohmann__json__namespace_autotoc_md1240}
