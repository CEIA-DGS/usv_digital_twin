\begin{DoxyEnumerate}
\item Compares two JSON values for inequality according to the following rules\+:
\begin{DoxyItemize}
\item The comparison always yields {\ttfamily \#!cpp false} if (1) either operand is discarded, or (2) either operand is {\ttfamily NaN} and the other operand is either {\ttfamily NaN} or any other number.
\item Otherwise, returns the result of {\ttfamily \#!cpp !(lhs == rhs)} (until C++20) or {\ttfamily \#!cpp !(\texorpdfstring{$\ast$}{*}this == rhs)} (since C++20).
\end{DoxyItemize}
\item Compares a JSON value and a scalar or a scalar and a JSON value for inequality by converting the scalar to a JSON value and comparing both JSON values according to 1.

!!! note "{}\+Comparing \`{}\+Na\+N\`{}"{} \begin{DoxyVerb}`NaN` values are unordered within the domain of numbers.
The following comparisons all yield `#!cpp false`:
  1. Comparing a `NaN` with itself.
  2. Comparing a `NaN` with another `NaN`.
  3. Comparing a `NaN` and any other number.
\end{DoxyVerb}
