Checks whether the input is valid JSON.


\begin{DoxyEnumerate}
\item Reads from a compatible input.
\item Reads from a pair of character iterators

The value\+\_\+type of the iterator must be an integral type with size of 1, 2 or 4 bytes, which will be interpreted respectively as UTF-\/8, UTF-\/16 and UTF-\/32.
\end{DoxyEnumerate}

Unlike the \doxysectlink{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2parse}{\`{}parse\`{}}{0} function, this function neither throws an exception in case of invalid JSON input (i.\+e., a parse error) nor creates diagnostic information.\hypertarget{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2accept_autotoc_md73}{}\doxysection{\texorpdfstring{Template parameters}{Template parameters}}\label{md_build_2dt__core_2__deps_2nlohmann__json-src_2docs_2mkdocs_2docs_2api_2basic__json_2accept_autotoc_md73}
{\ttfamily Input\+Type} \+: A compatible input, for instance\+: \begin{DoxyVerb}- an `std::istream` object
- a `FILE` pointer (must not be null)
- a C-style array of characters
- a pointer to a null-terminated string of single byte characters
- a `std::string`
- an object `obj` for which `begin(obj)` and `end(obj)` produces a valid pair of iterators.
\end{DoxyVerb}
 {\ttfamily Iterator\+Type} \+: a compatible iterator type, for instance. \begin{DoxyVerb}- a pair of `std::string::iterator` or `std::vector<std::uint8_t>::iterator`
- a pair of pointers such as `ptr` and `ptr + len`
\end{DoxyVerb}
