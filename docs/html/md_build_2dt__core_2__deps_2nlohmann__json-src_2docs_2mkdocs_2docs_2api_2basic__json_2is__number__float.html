<small>nlohmann::basic_json::</small>is_number_float

constexpr bool is_number_float() const noexcept;

This function returns #!cpp true if and only if the JSON value is a floating-point number. This excludes signed and unsigned integer values.

Return value

#!cpp true if type is a floating-point number, #!cpp false otherwise.

Exception safety

No-throw guarantee: this member function never throws exceptions.
